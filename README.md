# WORK Repository Skeleton v1.0

> 小規模チーム（5〜20名）が高品質・高セキュリティ・高再現性で開発するための共通基盤

## 概要

このリポジトリは、以下の標準に自然準拠した開発テンプレートです。

| 標準 | 対応内容 |
|------|----------|
| ISO 9001 | 品質管理・変更管理・継続的改善 |
| ISO 27001 (ISMS) | 情報セキュリティ管理・アクセス管理 |
| ISO 14001 | 環境配慮（環境負荷記録・Green CI） |
| Secure SDLC | セキュリティシフトレフト・脆弱性管理 |
| AI Governance | Claude Code / ChatGPT / GitHub Copilot 利用ルール |

## 対象ツール

- **GitHub** — ソースコード管理・CI/CD・Issue管理
- **Linear** — プロジェクト管理・スプリント管理
- **Claude Code** — AI支援開発
- **GitHub Actions** — 自動化パイプライン
- **Microsoft Teams** — コミュニケーション
- **SharePoint** — ドキュメント管理
