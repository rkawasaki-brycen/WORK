# AI Governance

## 目的

本ドキュメントは、チームにおけるAIツールを活用した開発を推進しつつ、それに伴うリスクを適切に管理するためのガバナンス方針を定めるものです。

AIを活用した開発の生産性向上と、セキュリティ・コンプライアンス・品質に関するリスク管理を両立させることを目的とします。

## 対象範囲

本ガバナンスは、チームメンバーが業務で使用するすべてのAIツールに適用されます。

対象ツールの例:
- Claude Code（Anthropic）
- GitHub Copilot
- ChatGPT / GPT-4（OpenAI）
- Gemini（Google）
- その他、コード生成・文章生成・分析に使用するAIサービス全般

## 基本原則

### 透明性（Transparency）

AIを活用して作成した成果物は、その旨を明示します。AIが生成したコード・文書・分析結果であることをチーム内で共有し、意思決定の根拠を可視化します。

### 説明責任（Accountability）

AIが生成した成果物の最終的な責任は、それを利用した開発者・担当者が負います。AIの出力を鵜呑みにせず、内容の正確性・適切性を自ら確認する責任があります。

### 人間による監視（Human Oversight）

AIの判断・提案は補助的なものとして扱い、重要な意思決定は必ず人間が行います。AIが生成したコードは人間によるレビューなしに本番環境へ適用しません。

### プライバシー・バイ・デザイン（Privacy by Design）

個人情報・機密情報をAIに入力しないことを原則とします。AIツールへのデータ送信は、情報分類ポリシーに従い、送信前に適切な判断を行います。

## ガバナンス体制

### ポリシーオーナー

| 役割 | 担当 | 責任 |
|------|------|------|
| AIガバナンス責任者 | プロジェクトマネージャー / セキュリティ担当 | ポリシーの策定・更新・承認 |
| 現場実施責任者 | 各チームのテックリード | ポリシーの周知・遵守確認 |
| 利用者 | 全開発メンバー | ポリシーの遵守・逸脱事例の報告 |

### レビュー体制

- **定期レビュー**: 四半期ごと（3ヶ月に1回）にポリシーの有効性を確認
- **イベント駆動レビュー**: 重大なインシデント発生時、または主要AIツールの仕様変更時に随時実施
- **年次改定**: 毎年4月に全体的な方針の見直しを実施

### インシデント報告

AIガバナンスポリシーに違反する事象、または違反の疑いがある事象が発生した場合は、速やかにAIガバナンス責任者へ報告してください。
