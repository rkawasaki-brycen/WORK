# Claude Code 利用ポリシー

## 概要

本ドキュメントは、開発チームにおける Claude Code（Anthropic社製AIコーディングアシスタント）の適切な利用を定めたポリシーです。すべての利用者はこのポリシーを遵守してください。

---

## 1. 利用許可範囲

以下の用途での Claude Code 利用を許可します。

| 用途 | 説明 |
|------|------|
| コード生成 | 新規機能の実装コード、ボイラープレートコードの生成 |
| リファクタリング | 既存コードの品質改善・構造最適化の支援 |
| デバッグ支援 | バグの原因調査、修正案の提示 |
| ドキュメント生成 | コメント、README、API仕様書などの文書作成支援 |
| コードレビュー支援 | コードの問題点の指摘、改善提案のサポート |

上記に該当しない用途で利用する場合は、事前にAIガバナンス責任者へ相談してください。

---

## 2. 禁止事項

以下の行為を禁止します。違反した場合は、インシデントとして報告・記録されます。

### 2.1 機密情報・個人情報の入力禁止

- **Confidential / Restricted に分類される情報**をプロンプトに含めることを禁止します
- **顧客の個人情報・機密データ**（氏名、住所、メールアドレス、契約情報など）をAIに送信することを禁止します
- **本番環境の認証情報**（APIキー、パスワード、接続文字列など）をコンテキストに含めることを禁止します

### 2.2 レビューなしのマージ禁止

- AIが生成したコードを、人間によるレビューを経ずにリポジトリにマージすることを禁止します
- 自動生成されたコードであっても、通常のPRフローを省略することはできません

### 2.3 その他の禁止事項

- ライセンスが不明または制限的なサードパーティライブラリのコードを大量に生成させること
- セキュリティ上問題のあるコード（脆弱性、バックドアなど）の生成を意図的に依頼すること
- 業務と無関係な個人的な利用

---

## 3. 機密情報の取り扱い

### 3.1 情報分類に基づく判断

AIへの情報送信は、社内のISMS情報分類ポリシーに従って判断してください。

| 情報分類 | AIへの送信 | 備考 |
|---------|-----------|------|
| Public | 許可 | 制限なし |
| Internal | 原則許可 | 送信する情報の必要性を確認すること |
| Confidential | 事前承認が必要 | AIガバナンス責任者の承認を取得してから送信 |
| Restricted | 禁止 | いかなる場合も送信しないこと |

### 3.2 承認プロセス

Internal以上の情報をAIに送信する必要がある場合:

1. AIガバナンス責任者またはセキュリティ担当者に承認依頼を提出する
2. 送信する情報の内容・理由・範囲を明示する
3. 承認を受けた後にのみ送信する
4. 送信した情報と目的をPR概要または作業ログに記録する

---

## 4. 著作権・ライセンス

### 4.1 生成コードのライセンス確認

- AIが生成したコードのライセンス確認責任は、そのコードを利用する**開発者自身**にあります
- 生成されたコードが既存の著作物（オープンソースライブラリ等）と類似している場合は、ライセンス条件を確認してください
- GPL等のコピーレフトライセンスが適用されるコードが混入しないよう注意してください

### 4.2 サードパーティコードの取り扱い

- 特定のサードパーティライブラリのコードを大量に再現・生成させることは禁止します
- 標準的なコードパターン・アルゴリズムの実装支援は問題ありません
- 不明な場合は法務・セキュリティ担当者に相談してください

---

## 5. レビュー責任

### 5.1 開発者の責任

AIが生成したコードであっても、そのコードをコミット・マージした**開発者が全責任を負います**。以下の点を必ず確認してください。

- コードの論理的な正確性
- セキュリティ上の問題がないこと（SQLインジェクション、XSS、認証バイパス等）
- パフォーマンスへの影響
- 既存コードとの整合性
- テストの網羅性

「AIが生成したから」という理由で責任を免れることはできません。

### 5.2 PRへのラベル付与

AIを活用して作成したコードを含むPull Requestには、**`AI-assisted`** ラベルを付与してください。

ラベルの目的:
- チームへの透明性確保
- レビュー時に特別な注意を促す
- 将来的な品質分析・改善に活用する

---

## 6. 利用記録

### 6.1 記録対象

以下の場合は、PR概要（Description）または作業ログにAI活用状況を記録してください。

- AIによってコードの大部分が生成された場合
- AIの提案によってアーキテクチャや設計方針を変更した場合
- 機密情報の承認を経てAIを利用した場合

### 6.2 記録フォーマット（推奨）

PR概要への記載例:

```
## AI活用状況

- 利用ツール: Claude Code
- 支援内容: ○○機能のリファクタリング、テストコード生成
- レビュー実施: 生成されたコードをすべて確認済み
```

## 7. CLAUDE.mdの管理

### 7.1 CLAUDE.mdの役割

`CLAUDE.md` はプロジェクト固有のClaude Code設定・コンテキストを定義するファイルです。リポジトリ内に配置することで、チーム全体で一貫したAI利用環境を共有できます。

### 7.2 記載してよい内容

- プロジェクトのアーキテクチャ概要
- コーディング規約・スタイルガイドへの参照
- よく使うコマンドや開発手順
- AIに対する一般的な指示（言語、フォーマット等）

### 7.3 記載禁止事項

`CLAUDE.md` には以下の情報を**絶対に含めないでください**。

- 認証情報（APIキー、パスワード、トークン）
- 本番・ステージング環境の接続先情報
- 個人情報・顧客情報
- Internal以上に分類される機密情報

機密情報はすべて環境変数または適切なシークレット管理ツールで管理してください。

### 7.4 管理方法

- `CLAUDE.md` はGitリポジトリで管理し、変更はPRレビューを経て反映します
- 定期的に内容を見直し、不要な情報や古い情報を削除してください

---

## ポリシー違反の報告

本ポリシーに違反する事象を発見した場合、または自身が誤って違反してしまった場合は、速やかにAIガバナンス責任者に報告してください。報告者を不当に不利益に扱うことはありません。
