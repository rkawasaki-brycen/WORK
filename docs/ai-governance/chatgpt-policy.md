# ChatGPT / OpenAI 利用ポリシー

**対象**: 開発チーム全員
**最終更新**: 2026-06-12
**ドキュメントオーナー**: 情報セキュリティ担当

---

## 1. 目的

本ポリシーは、開発チームにおける ChatGPT および OpenAI サービスの適切な利用を定め、情報漏洩リスクを最小化しながら生産性向上を実現することを目的とする。

---

## 2. 利用許可範囲

以下の用途での利用を許可する。

| 用途 | 具体例 |
|------|--------|
| 技術調査 | ライブラリの使い方調査、エラーメッセージの原因調査、アーキテクチャパターンの比較 |
| 文書作成支援 | 技術仕様書のドラフト作成、README の生成、議事録の要約 |
| アイデア出し | 設計アプローチの洗い出し、ブレインストーミング、機能名の命名 |
| 翻訳 | 英語ドキュメントの日本語訳、日本語仕様の英語化 |

---

## 3. 禁止事項

以下の情報を ChatGPT / OpenAI サービスに入力することを**禁止**する。

### 3.1 機密コード・ソースコード
- 自社プロダクトのビジネスロジックや独自アルゴリズムを含むコード
- APIキー、シークレット、認証情報が埋め込まれたコード
- 顧客向けシステムのソースコード全体

### 3.2 個人情報
- 氏名、住所、電話番号、メールアドレス等の個人を特定できる情報
- 従業員の評価・人事情報
- 顧客の個人情報（GDPR / 個人情報保護法の対象データ）

### 3.3 顧客データ
- 顧客のビジネスデータ、取引履歴
- 顧客との契約内容、価格情報
- 顧客環境の構成情報・インフラ情報

---

## 4. プランごとのデータポリシー

### 4.1 無料プラン (ChatGPT Free)
- 入力データはモデルのトレーニングに使用される**可能性がある**
- OpenAI のプライバシー設定でオプトアウト可能だが、デフォルトはオプトイン
- **業務利用は原則禁止**とする

### 4.2 有料プラン (ChatGPT Plus / Team)
- ChatGPT Plus: デフォルトではトレーニングに使用される。設定 → データ管理よりオプトアウト可能
- ChatGPT Team: 管理者がワークスペース全体でトレーニングデータ提供をオフにできる
- Team プランを使用する場合は、管理者が必ずトレーニングオプトアウトを設定すること

### 4.3 ChatGPT Enterprise
- 入力データはモデルのトレーニングに使用されない（契約上の保証あり）
- 入力・出力データは30日以内に削除される
- SOC 2 Type II 準拠、GDPR 対応
- 会社として Enterprise 契約を締結している場合のみ利用可

### 4.4 OpenAI API
- デフォルトではトレーニングに使用されない（2023年3月以降）
- Zero Data Retention (ZDR) オプションを申請することでログも保存されない
- API経由の利用は情報セキュリティ担当の承認を得た上で行うこと

---

## 5. ChatGPT Enterprise と通常版の比較

| 項目 | 通常版 (Free/Plus) | ChatGPT Enterprise |
|------|-------------------|-------------------|
| データのトレーニング利用 | デフォルトでオン（設定変更可） | なし（契約保証） |
| データ保持期間 | 規定なし | 最大30日 |
| SOC 2 準拠 | なし | Type II 準拠 |
| GDPR 対応 | 部分的 | 完全対応 |
| 管理者コンソール | なし | あり |
| SSO / SAML 対応 | なし | あり |
| 優先サポート | なし | あり |
| 利用状況の監査ログ | なし | あり |

## 6. 生成コンテンツの著作権に関する注意事項

### 6.1 著作権の帰属
- AI が生成したコンテンツの著作権の帰属については、各国の法制度が整備途上であり、確立した判例がない
- 生成されたコードや文章をそのまま成果物として提出する場合、著作権上のリスクが存在することを認識すること

### 6.2 第三者著作物の混入リスク
- ChatGPT はトレーニングデータに含まれる既存のコードや文章をベースに出力を生成するため、既存の著作物と類似したコンテンツが出力される可能性がある
- 生成されたコードは必ず内容を理解した上で採用し、既知のOSSライセンス条件との整合性を確認すること

### 6.3 推奨事項
- 生成されたコンテンツを**そのままコピー＆ペースト**することは避け、必ず自分の言葉や理解でリライト・修正を加えること
- 社外に公開する文書や製品に組み込むコードについては、特に慎重に著作権確認を行うこと

## 7. 出力内容の事実確認義務

### 7.1 ハルシネーション（幻覚）リスク
- ChatGPT は存在しないライブラリ名、関数名、APIエンドポイントを正確であるかのように出力することがある
- 統計数値、日付、固有名詞は特に誤りが多いため、必ず公式ドキュメントや信頼できるソースで確認すること

### 7.2 事実確認の義務
- 技術情報: 公式ドキュメント・GitHub・Stack Overflow 等の一次ソースで確認
- 法律・規制情報: 社内の法務担当または専門家に確認
- セキュリティ情報: CVEデータベース、ベンダーセキュリティアドバイザリで確認

### 7.3 確認なしに信頼してはいけない出力
- セキュリティに関するコードや設定
- 外部に公開するコンテンツ（ブログ、仕様書、提案書等）
- 法的・財務的な判断に関わる情報

## 8. 違反時の対応

本ポリシーに違反した場合、または違反の疑いが生じた場合は、直ちに情報セキュリティ担当に報告すること。詳細は `ai-incident-procedure.md` を参照。
