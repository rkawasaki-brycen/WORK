# 内部監査 概要

## 目的

本ドキュメントは、社内における内部監査の目的・スコープ・実施手順・報告方法を定め、品質マネジメントシステム (QMS) および情報セキュリティマネジメントシステム (ISMS) ならびに AI ガバナンスの有効性を継続的に確認・改善するための基準を示す。

内部監査の主な目的は以下のとおりである。

- 規程・手順書・ポリシーへの適合状況を客観的に確認する
- プロセスの有効性と効率性を評価し、改善の機会を特定する
- 外部審査・認証審査に向けた準備状況を把握する
- 経営層に対してマネジメントシステムの現状を報告する

## スコープ

| 監査種別 | 対象領域 | 適用チェックリスト |
|---|---|---|
| QMS 内部監査 | 要求管理 / 設計管理 / レビュー管理 / テスト管理 / 変更管理 / リリース管理 / 継続的改善 | `qms-audit-checklist.md` |
| ISMS 内部監査 | 情報分類 / アクセス管理 / 認証情報管理 / 脆弱性管理 / ログ管理 / インシデント管理 | `isms-audit-checklist.md` |
| AI ガバナンス監査 | ポリシー管理 / Claude Code 利用 / GitHub Copilot 利用 / インシデント / レビューと改善 | `ai-governance-audit-checklist.md` |

スコープ外となる領域を変更する場合は、監査責任者の承認を得た上で本ドキュメントを更新すること。

## 監査スケジュール

### 四半期内部監査

| 実施月 | 四半期 | 主な対象 |
|---|---|---|
| 3 月 | Q1 | QMS 全領域 + AI ガバナンス |
| 6 月 | Q2 | ISMS 全領域 + AI ガバナンス |
| 9 月 | Q3 | QMS 全領域 + AI ガバナンス |
| 12 月 | Q4 | ISMS 全領域 + AI ガバナンス (年次レビュー含む) |

- 監査は各四半期末月の第 2 週を目安に実施する。
- スケジュールは監査責任者が前四半期末までに確定し、関係者に通知する。

### 年次外部監査

| 項目 | 内容 |
|---|---|
| 実施時期 | 毎年 1 月〜2 月 (前年度実績をもとに実施) |
| 対象 | QMS / ISMS / AI ガバナンスの全領域 |
| 実施者 | 認定外部審査機関または第三者審査員 |
| 準備期間 | 外部監査開始 8 週前から内部監査結果の整備・是正措置の完了を確認 |

## 監査の実施手順

### 1. 計画フェーズ (監査開始 2 週前まで)

1. 監査責任者が監査計画書を作成する。
   - 監査目的・スコープ・スケジュール・監査員アサイン
2. 前回監査の指摘事項と是正状況を確認する。
3. 被監査部門に監査計画書を送付し、日程・準備事項を合意する。
4. 該当するチェックリストを最新化し、証跡収集の観点を確認する。

### 2. 証跡収集フェーズ (監査実施前)

1. 被監査部門は以下の証跡をあらかじめ準備する。
   - 規程・手順書・ポリシーの最新版
   - 直近四半期分の実施記録 (ログ、チケット、レビュー記録など)
   - 前回指摘事項の是正記録
2. 監査員は証跡をチェックリストの各項目に対応させ、事前確認を行う。

### 3. 監査実施フェーズ

1. オープニングミーティング (15〜30 分)
   - 監査目的・進め方・スコープを被監査部門に説明する。
2. 監査実施 (チェックリストに従い実施)
   - チェックリストの各項目について、証跡確認・ヒアリング・観察を組み合わせて評価する。
   - 評価結果を「結果」列 (適合 / 軽微な不適合 / 重大な不適合 / N/A) に記録する。
   - 不適合が判明した場合は、事実を具体的に「備考」列へ記録する。
3. クロージングミーティング (30〜60 分)
   - 監査結果の速報を被監査部門へ報告する。
   - 不適合・観察事項について認識を合わせる。

### 4. 報告フェーズ (監査完了から 1 週間以内)

1. 監査員が監査報告書を作成する。
   - 監査概要・実施結果サマリ・指摘事項一覧・推奨事項
2. 監査責任者がレビューし、承認する。
3. 報告書を被監査部門リーダーおよび経営層へ共有する。
4. 指摘事項を課題管理システム (GitHub Issues など) へ登録する。

### 5. 是正措置フェーズ

| 指摘区分 | 是正期限 | 確認方法 |
|---|---|---|
| 重大な不適合 | 指摘から 30 日以内 | 監査員によるフォローアップ確認 |
| 軽微な不適合 | 指摘から 90 日以内 (次回監査まで) | 次回監査時に証跡確認 |
| 観察事項 | 改善推奨 (期限は任意) | 次回監査時に状況確認 |

## 結果の記録と評価基準

各チェックリスト項目の評価は以下の基準で行う。

| 評価 | 記号 | 定義 |
|---|---|---|
| 適合 | Yes | 要求事項を満たす証跡が確認できた |
| 部分適合 | Partial | 要求事項を部分的に満たすが、改善の余地がある |
| 不適合 | No | 要求事項を満たす証跡が確認できなかった、または明確な違反が認められた |
| 非該当 | N/A | 当該項目がプロジェクト・組織に適用されない |
