このガイド1本で以下がすべて完了します。

- アカウント設定（GitHub / Linear / Teams / MFA）
- 開発環境構築（Git / 言語ランタイム / Claude Code CLI）
- 必須ドキュメントの読了
- セキュリティ設定の確認

- 最初のイシュー着手

所要時間の目安: 9:00-17:00（終業までに完了）
