## 使用方法

1. リスクを識別したら、下表に新規行を追加する。
2. リスクIDは `RISK-[YYYY]-[連番3桁]` の形式で採番する（例: RISK-2026-001）。
3. スコア = 可能性 × 影響度 で算出する。
4. レベルはスコアに応じて自動的に判定する（低:1-4、中:5-9、高:10-16、重大:17-25）。
5. 月次レビュー後に内容を更新し、最終更新日を記録する。

### ステータス区分

| ステータス | 説明 |
|---|---|
| 識別済 | リスクを識別したが、対応計画が未策定 |
| 計画中 | 対応計画を策定中 |
| 対応中 | 対応策を実施中 |
| モニタリング中 | 対応済みだが継続的に監視 |
| 解消済 | リスクが解消または許容範囲内に低減 |
| 受容 | 意図的に受け入れることを決定 |
